## 🎯 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/bhoomijn/hackerrank-python.git
cd hackerrank-python
```

2. Navigate to the desired difficulty level:
```bash
cd easy  # or medium/hard
```

3. Review solutions and run them:
```bash
python3 problem_name.py
```
